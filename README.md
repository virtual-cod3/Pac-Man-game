# Pacman Game 🟡👻

A classic Pacman game built with HTML, CSS and JavaScript.

## How to Play
- Use `Arrow Keys` to move Pacman
- Eat all the dots 
- Avoid the ghosts
- Collect power pellets to eat ghosts

[Play the Game]((https://virtual-cod3.github.io/pacman-game/)

## Tech Used
HTML5, CSS, JavaScript.
