# 🎮 Pac-Man Ultimate

A responsive browser-based Pac-Man game built using **HTML, CSS, and JavaScript**.

## ✨ Features

* 🎮 Classic Pac-Man style gameplay
* 👻 Multiple ghosts with different movement behavior
* 🟡 Normal pellets and power pellets
* ❤️ 3 lives system
* 🏆 Score and high-score tracking
* 🎯 3 playable levels
* ⏸️ Pause and Resume
* 🔄 Restart option
* 📱 Responsive design for desktop, tablet, and mobile
* 👆 Mobile touch controls
* 👆 Swipe controls
* ⌨️ Keyboard controls using Arrow Keys / WASD
* 🏁 Game Over and Victory screens
* 💾 High score saved using browser local storage

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* HTML Canvas
* LocalStorage

## 🎮 Controls

### Desktop

* **Arrow Keys** — Move Pac-Man
* **W A S D** — Move Pac-Man
* **Space / Esc** — Pause or Resume

### Mobile

* Use the on-screen directional buttons
* Swipe on the game screen to move

## 🚀 How to Play

1. Open the game.
2. Click **START GAME**.
3. Eat all the pellets.
4. Collect power pellets to defeat ghosts.
5. Avoid the ghosts.
6. Clear all three levels to win.
